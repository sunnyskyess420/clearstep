# ClearStep

**One home for five free tools for coping and DBT — support in the moment, and skills that last.**

Live app: https://clearstep-mocha.vercel.app

## What's inside

Five small, focused tools for the hard moments — and the skills you build between them. Open it mid-spiral for support, or open it on a calm day and practice.

## Built with

- Next.js · TypeScript · Tailwind CSS
- Deployed on Vercel

## Run it locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
